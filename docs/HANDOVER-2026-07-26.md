## 1. The headline finding: `.gitignore` was eating the work

`.gitignore` contained a blanket `*.html` (line 50) and `*.csv` (line 48).

Every artefact the 25 July handover recorded as "done" but which appeared to be missing was in fact **sitting on disk the whole time** — `git add` silently skipped it, so it was never committed and never deployed:

| File | Written | Swallowed by |
|---|---|---|
| `lead-funnel/news/land-valuations-2026.html` | 24 Jul 11:41 | `*.html` |
| `lead-funnel/news/toondah-harbour-whats-next.html` | 24 Jul 11:41 | `*.html` |
| `lead-funnel/news/city-plan-your-block.html` | 24 Jul 11:42 | `*.html` |
| `lead-funnel/news/birkdale-olympics-2032.html` | 24 Jul 11:42 | `*.html` |
| `newsletter/issue-01.html` | 24 Jul 11:48 | `*.html` |
| `lead-funnel/newsletter-embed-snippet.html` | 24 Jul 11:17 | `*.html` |
| `newsletter-import-resend.csv` | 24 Jul 11:28 | `*.csv` |

Only `news/index.html` reached production, because it had been force-added earlier. The 24 Jul deploy summary said *"1 new file uploaded"* — that was the tell, missed at the time.

**Fixed.** `.gitignore` now carries negation rules:

```
!lead-funnel/**/*.html
!lead-funnel/*.html
!newsletter/*.html
```

`newsletter-import-resend.csv` is deliberately left ignored — the repo is public and it is a contact export.

**Lesson for future sessions:** after any deploy, check the Netlify summary file count against what you expected. And never trust a handover that says "done" without a commit hash.

Two gotchas worth recording:

- Resend's visual editor **strips the `|fallback`** from merge tags — `{{{contact.first_name|there}}}` normalises to `{{{contact.first_name}}}`, which renders "Hi ," for any contact without a name. Greeting is now a plain "Hi there,". The fallback syntax only survives via the API.
- Resend wraps every image in a container with `margin-left:0`, overriding `margin:0 auto` in the HTML. Image centring must be set through the editor's own alignment control.

`newsletter/issue-01.html` in the repo now matches the Resend draft.

**Before sending:** test send to yourself, confirm the logo renders (images are blocked by default in many clients).
